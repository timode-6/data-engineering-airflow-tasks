# ZillaCode in PySpark

Solutions to the [ZillaCode](https://github.com/davidzajac1/zillacode) problems
in PySpark: 10 easy ones, all medium and all hard.

## Running them

```
git clone https://github.com/davidzajac1/zillacode
cd zillacode
docker compose up
```

Open localhost:5173/questions, pick a problem, switch the language to PySpark,
replace the editor's code with the file and run it.

Each file is exactly what goes into the editor. The app only takes the `etl`
function and rejects any code outside it, so the notes are comments inside the
function.
